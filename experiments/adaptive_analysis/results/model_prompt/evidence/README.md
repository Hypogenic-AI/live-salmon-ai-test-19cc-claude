# Reproducible Live Salmon model × prompt evidence

This package contains all **180 formal and 36 separate development episodes**, including unsuccessful runs, original model calls, configurations, costs, prompts, analysis results, and frozen source. It supports offline reconstruction and deterministic reporting. No new model calls or statistical fits are needed.

The experiment compares three requested model profiles, P0/P1 instructions, fixed evidence followed by one model selection (A), and a feedback-based analysis loop (B). Formal seeds are 301–305; development seed 9010 is separate. The earlier GPT-4.1 pilot informed P1 and is historical context, not pooled into these primary results.

Read [REPORT.md](REPORT.md) for outcomes and limitations and [EXPLANATION_REVIEW.md](EXPLANATION_REVIEW.md) for the separate assistant-assisted explanation evidence review. Five seeds per cell support descriptive comparisons, not a general model ranking. Primary outcomes are deterministic; explanation review is not part of the primary score.

## Why the archive is compact

Raw candidate tables recur across model and prompt configurations. The archive stores 65,016 distinct, exact candidate objects in 18 data-case banks, replacing 408,576 saved-object occurrences with ordered references. Deduplication uses exact JSON values and key order, without rounding or dropping fields. Different exact versions are retained when necessary. Every raw episode is restored with its **original byte-level SHA-256**, including original object order and formatting.

- `banks/*.json.gz`: candidate objects, grouped by development/formal seed and data condition.
- `episodes.jsonl.gz`: complete episode bodies with ordered candidate references. Model-call text, usage, failures, and configuration fields remain intact.
- `supporting-files.tar.gz`: original freeze/progress/source snapshot, English reports and complete audit records, frozen source files, and the offline reporter.
- `manifest.json`: expected restored paths, byte counts and SHA-256 values, coverage, and compression metadata.
- `restore.py`: standard-library-only restorer; no dependencies, network, credentials, or model APIs.
- `VERIFICATION.json`: byte reconstruction and relocated reporting checks performed when packaging.
- `SHA256SUMS`: checksums of every other packaged file. These are integrity checks, not signatures of authorship.

The package excludes Chinese-language presentation files; all experimental evidence is retained. Historical absolute paths inside original raw JSON and provenance metadata are intentionally preserved. They are not used to locate files during restoration or reporting. Public Markdown uses relative links.

## Restore and verify

From this package directory:

```sh
python3 restore.py /tmp/live-salmon-restored
```

Use a new output directory outside the package. The restorer checks package integrity, safely extracts regular files, reconstructs all 216 original episode files, and verifies every restored file against its original SHA-256. It also checks all frozen source hashes. Restore requires about 677 MB of disk space.

Optional independent package integrity check on macOS:

```sh
shasum -a 256 -c SHA256SUMS
```

On Linux use `sha256sum -c SHA256SUMS`.

## Reproduce the numerical reports offline

Use an existing Python environment with the frozen dependencies listed in `raw/freeze.json` and `source/live-salmon/uv.lock`. Then run:

```sh
cd /tmp/live-salmon-restored
python3 -B tools/summarize_model_prompt_experiment.py raw reproduced-reports \
  --repo source/live-salmon --require-complete
```

The reporter validates configuration, source, prompt, raw/progress coverage, and input hashes. For the auxiliary minimum-CV reference it regenerates the frozen synthetic data, verifies its fingerprint, and replays saved coefficients; it does not refit. Its `metrics.json` should match `reports/metrics.json` after excluding only the top-level generation timestamp and absolute input-file paths. All outcomes, costs, trajectories, and paired contrasts must match. The separate assistant-assisted explanation review is preserved evidence and is not regenerated by the reporter.

The source snapshot includes the historical execution wrapper for provenance. **Do not run that wrapper to reproduce reports**: it was designed for paid execution and the original local environment. Fresh model experiments require an explicitly configured execution driver and credentials; they are not part of this offline procedure.

## Scope

No hidden environment files, credentials, Git history, virtual environment, or Python caches are included. Source comes only from the archived frozen snapshot. The primary archive has complete model × prompt evidence; the prior pilot is separate historical work. A known-prefix scan was applied to all uncompressed included payloads, with matching text suppressed on failure; this is a narrow screening check rather than a guarantee about arbitrary secret formats.
